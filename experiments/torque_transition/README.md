## 高斯点和模态

本预检把128定义为非线性/观测量的每方向Gauss求积节点数。Dirichlet组合基
phi_k=P_k-P_(k+2)，N个模态最大次数N+1；保持2q-1>=3(N+1)，所以最大N=84。
q160对应105模态，q192对应126模态。线性算子精确装配，后端还有独立的全散度检查节点。
若128原意为未去混叠的线性基准点、再另增非线性求积点，需要另外确认，不可混同。

## 接口与运行

`preflight.py`拥有短时模型/物理观测/测试调度，复用公共SpectralModel、格式、控制器工厂
和记录工具。不改变求解器、接受判据或校正次数。threadpoolctl来自锁定dev依赖。
`analyze_preflight.py`只读显式目录，以NumPy Legendre多项式独立重构，不构造动力模型。

```sh
# 以下仅短时测试；设置六项线程环境为1后执行
uv run --locked python -m experiments.torque_transition.preflight probe \
  --case 4 --nodes 128 --duration 1 --output runs/torque_transition/example-smoke

uv run --locked python -m experiments.torque_transition.preflight benchmark \
  --seed /absolute/path/to/seed/final.npz --duration .2 \
  --output runs/torque_transition/example-benchmark
```

单probe限制duration<=100，无生产启动选项。输出final/history/field_samples.npz、
scalar_samples.json、result.json；后者含物理参数、线程池、来源和数据校验。
每100接受步写progress.json/latest.npz：这是**测试进度态**，不含PI历史，
不能称为严格checkpoint。种子用于同场性能回放，重置PI并采用共同h0=.001；
与正式候选h0=1e-4区别记录。所有计时保留原阶段与完整散度检查，预热不提交状态。

并发组先各自设置/预热，在文件barrier释放后共同计时；记录积分时间和释放到退出时间。
吞吐以worker数×物理时长/释放到退出墙钟计算，包含保存/退出开销、不含设置。
每组合三次正逆交错重复；同组各worker最终场一致性检查，但不宣称整个混合13任务
批次的总完成时间已最优。数值线程池实测来自NumPy/SciPy OpenBLAS。
