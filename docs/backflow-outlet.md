# 可选出口回流耗散

用户在 Re1000 的自然出口失败及同状态短窗对照后，要求继续计算测试。
`OpenFlowModel(..., outlet_treatment="backflow_damped")` 和圆柱配置中的同名键
显式启用这一模型；默认仍为 `natural`，未显式指定的旧配置不增加默认键或改变身份。

令 a=U·n，a⁻=max(-a,0)。新出口牵引为

\[
\nu\partial_n U-pn=-\tfrac12 a^- U.
\]

在原反对称体积对流及一致边界通量之外，左端增加
\(\frac12\int_{\Gamma_{out}}a^-U\cdot v\)。只作用于未约束的开放面，
不在固定入口、壁面或圆柱上施加。若出口没有回流，该项严格为零。
出口的有效非线性自功成为 \(\frac12\int a^+|U|^2\)，其中 a⁺=max(a,0)。

SAV 的边界工作同步采用完整新非线性载荷的已知迹工作减去有效边界自功，
保持相等状态下 `<N_free(U),u> + ell(U)=0`。没有改时间阶段、实根选择或默认线性残差门槛。
物理压力仍从瞬时约束速度率求解，圆柱表面应力仍为 `nu*grad(U)-pI`。

保存的 `convective_boundary_power` 保留原物理对流通量含义；
新增非负 `outlet_backflow_dissipation` 单独记录额外项。
新数据以 `dfg2d2_backflow_damped`、专属边界和压力标签区分，
不能继承 DFG2D-2 自然出口的 Re100 参考资格。配对分析必须使用相同出口模型。

这是回流时不同的数学边界条件，不是对原 DFG 出口的等价加速。
局部非线性能量恒等式和短窗计算通过，不构成非零入口、变步长问题的全局稳定性证明，
也不代替时间/空间敏感性或长时间尾流验证。
