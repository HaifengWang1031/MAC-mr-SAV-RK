# 固定次数的冻结因子SAV阶段校正

2026-11-04用户明确要求以固定校正替代生产格式的多项式实根枚举与Newton：
一阶、二阶每阶段各一次，三阶每阶段两次。比较实验已验证三阶两次校正在所测细步长
区间具有与自洽标量求解近乎相同的速度误差；这项实现决定不等于一般PDE收敛证明。

各阶段先求两个同矩阵Stokes响应，以前一阶段r预测，冻结P_{p-1}(z)后用正分母标量商更新。
用倒数第二次迭代值的P与最后一次r共同构造速度、压力和SAV功，检查的是实际冻结阶段方程。
一次/两次是格式的固定定义，无容差停止、额外Newton、根选择或Stokes回退。
ADR0001的边界transport、lifting功和压力规范仍通过原动量adapter进入相同配对。

校正值一般不是旧自洽多项式的根，因此新记录保存校正序列、预测值和冻结因子，
不能把冻结残差解释成旧多项式根残差。保留历史数组布局与来源的读取，
旧结果和冻结源码不变，新运行由变化后的代码来源标识。以后重做旧实验须选择真实旧源码。
