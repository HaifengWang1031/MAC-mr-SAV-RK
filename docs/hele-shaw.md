# Hele–Shaw翼型的Darcy参照与惯性Brinkman模型

## 范围与方程

固定、贯穿整个板间隙的闭尾缘NACA0012，平面区域为外矩形减去翼型实体。
弦长c、完整板间距b、运动黏度nu、密度rho，角度以+x来流下机头上仰为正，绕四分之一弦点旋转。
当前为单一抛物线剖面的二维约化模型；未执行三维校核，不声称任意Re或间隙下均适用。

采用MWR闭合：

\[
 a_t u_t+a_c(u\cdot\nabla)u-a_v\nu\Delta u+12\nu u/b^2+\nabla(p/\rho)=f,
 \quad\nabla\cdot u=0,
 \quad(a_t,a_c,a_v)=(6/5,54/35,6/5).
\]

除以a_t后，原时间格式看到nu_eff=nu、beta=9/7、sigma=10nu/b²和pi=p/(a_t rho)。
采用[薄缝加权残差模型式18–19a](https://arxiv.org/html/2511.03956v2)。
`convection=false`关闭非线性项，得到线性非定常Brinkman对照；不改变其余闭合系数。

独立Darcy参照解满足u=-b² grad(p)/(12rho nu)、Delta p=0。标量压力采用连续P2有限元；
端部给p_in和p_out，其余边界弱不穿透。连续P2速度只作显示投影，通量从原压力梯度计算；
它不是局部守恒的混合Darcy方法。参照对应最终目标压差的稳态，不是瞬态精确解。

## 边界与压力

Brinkman模型在翼型和横向侧壁给平均速度零；两个端部给压力型自然应力，出口储液压力作为零基准。
内部归一化形式为`nu * partial_n(u) - pi*n = -p_ext*n/(a_t*rho)`，切向自然应力为零。
该条件不等同于在边界每个压力自由度上直接令p=p_ext。自然应力已经固定压力常数，不再加零均值。
压差采用五次smoothstep从0爬升至设定值；`ramp_time=0`表示直接施加恒定压差。
所有速度Dirichlet迹固定为零，因此启动不需要时变入口lifting。

可选`backflow_damped`只在出口增加耗散，不作用于有意流入的入口；默认natural。
对流体积项、开放通量、附加耗散及SAV标量边界配对统一乘beta。
SAV保持已有六种格式、各自G/Q、全部候选根和残差，r0=0；未引入新的时间公式。
板间阻力隐式进入`A_eff=A+(sigma/nu)M`，两个SAV右端仍共享同一个阶段矩阵。
通用FEM的reaction_coefficient默认零，零分支使用原始矩阵对象；非零固定速度迹的质量交叉项也被计入。

阶段增量乘子不作为物理压力。计算结束后，对每个保存快照作瞬时约束速度率/压力求解，
再乘a_t*rho，保存为`physical_pressure`。只读分析读取此数据，不重建动力模型或求解压力。
保存的`model_force_per_span`为归一化梯度应力积分乘a_t*rho，即MWR方程定义的模型力；
不把它作为未经三维校核的实验升阻力。若展示模型厚度积分力，还需乘b。

## 网格与尺度

Gmsh仅在生成阶段需要，通过可选mesh extra安装。加载与分析使用真实保存的MeshTri。
翼型是显式多边形，流体为仿射三角形，速度P2/压力P1；增加速度阶数不会自动提高几何阶数。
分别控制surface_points（轮廓）、far_size（远场）、layer_cells（近壁h）。
默认近壁尺寸h_min=b/(sqrt(10)*layer_cells)，黏性—摩擦尺度ell=b/sqrt(10)。
横向长壁使用解析距离，避免距离场采样间隔大于薄层尺度。
检查完整边界覆盖、约束轮廓、区域连通、单孔Euler示性数、面积和最小角。
两级网格仅作敏感性检查，正式精度声明仍需独立几何、空间、时间和外域研究。

## 2026-11-02 压力入口角点修复

首个Re_D=10000长算在t=.74095出现入口下角点速度尖峰，随后步长降到下限。
对同一保存状态、同一网格、同一SDIRK3-mr-ccSAV及h=1e-7回放，
原自然入口峰值668.11增至674.63；线性残差仍约5e-16。
该状态的入口物理对流功为-8.22e4，负的边界自功可以给自由入口扰动供能。

显式新选项`inlet_treatment=energy_stable_pressure`在入口增加

\[
 C_{\rm in}(U;v)=\frac{\beta}{2}\int_{\Gamma_{\rm in}}
            \max(-U\cdot n,0)\,U\cdot v,
 \qquad D_{\rm in}=C_{\rm in}(U;U)\ge0.
\]

归一化边界条件相应成为
`nu*partial_n(U)-pi*n=-p_ext*n/(a_t*rho)-beta/2*max(-U.n,0)*U`。
这是改变压力入口的动能应力条件，输入p_ext为外部压力型载荷，
不能把新条件当作原先纯自然应力条件或逐点静压Dirichlet。
采用与已有出口修正相同的方向性牵引机制；关于该类边界能量控制，参见
[Ni--Yang--Dong 2019, Introduction](https://arxiv.org/html/1807.07056v1)。
本实现不是该论文提出的OBC-A/B/C，也不继承其物理精度验证。

同一修正transport同时用于动量载荷与SAV边界功，之后统一乘beta，
因此仍有`<N(u),u>_M+ell(u)=0`；未改变SAV阶段、G/Q或根选择。
同状态回放中峰值降至661.16。若出口同时选择已有backflow_damped，
全部开放端的净对流自功成为`beta/2*integral max(U.n,0)*|U|^2 >= 0`。
这说明空间边界能量项的符号，不构成SDIRK3全离散稳定性或高Re精度证明。

默认入口继续为natural，旧配置不补新键。新边界/压力标签、HDF5入口属性和运行身份单独保存；
物理对流功、入口修正D_in和出口修正分别记录，能量诊断包括全部项。
可选velocity_limit/scalar_limit为显式运行资格门槛，超限终止并保存已接受前缀，不裁剪状态。
启用新选项的运行由程序原子更新progress.json，记录t/r/最大节点速度及两侧入口角点速度。

独立解析检验给出入口修正功`2*beta/7`，并覆盖零r配对、出口组合、线性极限、
全部SDIRK3阶段、配置/读写和超限前缀。重跑先从零初值验证到T=1.1，
再从零独立运行Re_D=10000到T=20；入口修正保持，生产使用既有回流耗散出口。
